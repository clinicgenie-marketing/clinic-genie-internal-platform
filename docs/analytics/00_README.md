## Scope
Overview, Traffic, Behaviour, authorised connection settings, imports for historical gaps, report exports and sync health. Search Console reporting is embedded under Traffic and linked to the existing SEO module. No Ads campaign management, CRM, paid intelligence service, session recording, heatmaps or custom booking calendar. Scheduled data synchronisation is infrastructure within this request, not a general workflow-automation product.

## Design precedence
Use the running application's design system after repository inspection. The supplied design specification is a fallback, not permission to restyle the platform. It specifies #DDF7F8, #136C72, #173C40, #F6FBFC, #FFFFFF, #D7E7E9, Helvetica/Arial/system fonts and a 4/8px spacing scale. Earlier project context also mentions Plus Jakarta Sans. Preserve the actual installed font and record which source governs; do not change fonts as part of Analytics.
